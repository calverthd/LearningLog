About Learning Log

Learning Log is a Django web application that helps you track topics you’re studying and record notes about them. Each topic belongs to a registered user, ensuring that your data is private and owned by you.

Features include:

  • User accounts with login and registration
  • Ability to create topics and add entries
  • Ownership of data — only you can see your topics and entries
  • Responsive design using Bootstrap for compatibility across devices
